# chart-to-data

논문·기술 보고서에 실린 **라인차트(꺾은선 그래프)** 이미지에서 그래프 위 좌표값을 자동으로 추출해
**CSV로 내려받을 수 있게 해주는 설계 검증 보조 도구**입니다.

그래프를 눈으로 읽고 손으로 옮겨 적는 수작업을 줄이기 위해 만들었습니다.

## 무엇을 하나요

1. PDF 또는 JPG 파일을 올립니다.
2. 그래프가 있는 영역을 마우스로 드래그해 지정합니다.
3. AI가 축 범위·단위·계열(선) 목록을 읽어오면, 화면에서 맞는지 확인·수정합니다.
4. 값을 뽑을 계열(선) 하나를 고릅니다.
5. X축을 50등분한 지점의 좌표값을 자동으로 추출하고, 필요하면 특정 X값을 추가로 조회합니다.
6. 원본 이미지와 결과 표를 나란히 확인한 뒤 CSV로 내려받습니다.

업로드한 파일과 추출 결과는 **서버에 저장되지 않습니다.** 브라우저 세션에만 있다가 새로고침하면 사라집니다.

## 어떻게 동작하나요 — 하이브리드 판독

정확도를 높이기 위해 두 단계로 나눠 처리합니다.

```
AI (OpenAI 비전 모델, 서버에서 1회만 호출)
  → 그래프 영역(plotBox), 축 눈금·범위·단위, 계열 목록과 색상 읽기

앱 (브라우저에서 직접 계산, 외부 호출 없음)
  → 축 선 픽셀을 찾아 plotBox·눈금 위치 보정
  → 계열 색을 따라 픽셀을 추적해 선의 위치를 정밀 측정
  → 축 변환식으로 실제 좌표값 계산
```

AI에게 좌표까지 직접 읽게 했을 때는 실측 오차가 평균 5.9~7.7%로 목표(±3%)를 넘었고 실행마다 값이
달라졌습니다. 그래서 AI는 "어디를 봐야 하는지"만 알려주고, 실제 좌표 계산은 앱이 픽셀 단위로 직접
합니다 — 같은 그래프면 항상 같은 값이 나옵니다(재현율 100%).

자세한 설계 배경은 [DESIGN.md](DESIGN.md)에 있습니다.

## 정확도

검증용 그래프 12개(합성 8개 + 논문형 4개)의 17개 계열이 **최대 오차 0.82% 이내**로 목표(±3%)를 통과했습니다.
자세한 수치와 측정 방법은 [VERIFICATION.md](VERIFICATION.md)를 참고하세요.

### 알려진 한계

- **흑백 점선 차트**는 지원하지 않습니다 — 계열 색으로 선을 구분하는 방식이라 무채색끼리는 갈라낼 수 없습니다.
- AI 판독은 실행할 때마다 축 범위·색상 등의 값이 조금씩 다를 수 있습니다(픽셀 추적 자체는 100% 재현됩니다).
  추출 전 화면에 표시되는 축 정보를 꼭 확인해주세요.

## 시작하기

```bash
npm install
```

`.env` 파일을 만들고 OpenAI API 키를 넣습니다.

```
OPENAI_API_KEY=sk-...
```

```bash
npm run dev
```

http://localhost:3000 에서 확인할 수 있습니다.

## 기술 스택

- **Next.js** (App Router) — 프론트엔드와 서버 API를 한 프로젝트에서 처리
- **OpenAI 비전 모델** — 그래프 영역·축·계열 정보 판독 (서버 쪽 코드에서만 호출)
- **Zustand** — 브라우저 세션 상태 관리 (서버 저장 없음)
- **pdfjs-dist** — PDF를 브라우저에서 직접 이미지로 변환
- **Zod** — AI 응답 형식 검증
- **Tailwind CSS** — 화면 스타일

DB가 없고 로그인 기능도 없습니다. 업로드한 이미지 조각은 판독을 위해 OpenAI로 전송되므로,
**공개된 논문·기술 보고서 등 공개 자료만 사용해주세요.**
