# 검증용 그래프 (PLAN.md 28번)

정답값을 **수식으로 알고 있는** 그래프 8개입니다. 각각 다른 위험 요소를 하나씩 담았습니다.
수식으로 그리므로 언제든 똑같이 다시 만들 수 있고, 추출값과 정답을 정확히 비교할 수 있습니다.

## 보는 방법

개발 서버를 켠 뒤 브라우저에서 아래 주소를 엽니다.

```bash
npm run dev
```

http://localhost:3000/test-charts/ — 8개 그래프가 화면에 그려지고, 각각 JPG로 내려받을 수 있습니다.

### 논문형 그래프 (2026-08-14 추가)

C1~C8은 **테두리가 곧 축 최솟값~최댓값**이라 그리게 되어 있습니다. 실제 논문 그래프는 데이터 양옆에 여백이 있어
테두리와 눈금 범위가 다르고, C1~C8만으로는 그 차이에서 생기는 오차(최대 57%)를 잡아내지 못했습니다.

## 측정 방법 (PLAN 29번)

가장 쉬운 방법은 **자동 측정 화면**입니다 (개발 모드 전용).

- http://localhost:3000/dev-verify — 12개 그래프를 한 번에 재서 표로 보여줍니다.
- http://localhost:3000/dev-verify?noticks=1 — 눈금 보정을 끄고(예전 방식) 재서 개선 전후를 비교합니다.

오차율은 **Y축 전체 범위 대비** 백분율로 잽니다.

```
오차(%) = |추출값 − 정답값| / (yMax − yMin) × 100
```

재현율은 같은 그래프를 여러 번 추출해 값이 얼마나 같은지로 잽니다.
현재 방식(픽셀 추적)은 계산이라 같은 이미지·같은 영역이면 **항상 완전히 동일**해야 합니다.
